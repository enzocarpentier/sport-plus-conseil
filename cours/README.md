# 📚 Espace Cours, Consignes & Références Académiques

Ce dossier est dédié à rassembler tous vos supports de cours, consignes d'évaluation, grilles de notation et références théoriques pour nourrir et crédibiliser le dossier officiel **Sport Plus Conseil**.

---

## 🗂️ Organisation des dossiers

Vous pouvez déposer vos fichiers directement ici ou coller vos textes dans les documents préparés :

| Dossier | Fichiers prévus | Usage |
| :--- | :--- | :--- |
| **`cours/consignes/`** | `consignes_dossier.md` | Collez ici le sujet, les attendus du professeur, le barème, le nombre de pages imposé, les questions à traiter. |
| **`cours/modules/`** | `notions_et_theories.md`<br>`notes_de_cours.md` | Vos cours, slides, théories universitaires (marketing du sport, économie, sociologie, droit). |
| **`cours/ressources/`** | `bibliographie_et_references.md`<br>`lexique_et_mots_cles.md` | Ouvrages conseillés, articles scientifiques, lois / règlements, vocabulaire obligatoire. |

---

## 💡 Types de documents que vous pouvez déposer
- **Fichiers texte / Markdown (`.md`, `.txt`) :** Vous pouvez copier-coller directement vos notes ou les textes de vos slides dans les fichiers prévus.
- **Fichiers PDF / Word (`.pdf`, `.docx`) :** Vous pouvez les glisser-déposer directement dans ces dossiers.
- **Images ou captures de consignes (`.png`, `.jpg`) :** Vous pouvez les glisser dans `cours/consignes/`.

---

## 🚀 Prochaine étape
Dès que vous avez collé ou déposé vos éléments, dites-le-moi ! J'analyserai vos cours et j'adapterai immédiatement le dossier A4 pour intégrer :
1. Les **notions exactes et la terminologie** de votre professeur.
2. Les **auteurs et théories clés** du cours cités en corps de texte.
3. Le **respect strict de la grille de notation** et des consignes.
